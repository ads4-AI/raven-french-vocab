# Raven · French vocab · 12 Oct

Single file app: `index.html` (145 words, Allez 2 Unit 5 "En pleine forme !"). No internet, no login needed.

## Open it
- **Mac / laptop:** double-click `index.html` (opens in Safari or Chrome). Or drag it into a browser window.
- **iPhone:** the Files app's preview does NOT run the app's buttons (Quick Look blocks JavaScript). Open it from a web link instead (see the parent's note), or use the laptop tonight.
- Shortcut links: `index.html#type` opens in Type it mode, `#quiz` in Quiz mode.

## How to use
1. **Flashcards:** say the answer out loud, tap the card (or Space) to flip. "I knew it" (→) or "Still learning" (←). Still-learning cards come back a few cards later and go into ★ Hard ones.
2. **Type it:** type the French. Accents and capitals don't matter; accent buttons are there if wanted. Small typos count as "Nearly".
3. **Quiz:** pick 1 of 4 (keys 1-4).
- EN→FR button swaps direction. ◐ toggles dark mode.
- Decks: All, Food, Lifestyle, Diet, Phrases, ★ Hard ones (saved on that device/browser).
